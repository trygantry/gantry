Mobile Release Gate Not Detected

Add the canonical Action, then make its job a required check on the protected release branch.

.github/workflows/gantry.yml 
name: Gantry mobile release gate
on:
  pull_request:
  workflow_dispatch:

jobs:
  mobile-release-gate:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write
    steps:
      - name: Checkout repository
        uses: actions/checkout@v5
        with:
          fetch-depth: 0

      - name: Build the signed release candidate
        run: ./scripts/build-release-candidate.sh

      - name: Audit the exact candidate
        uses: trygantry/gantry@v1
        with:
          mobile-artifact: build/app/outputs/bundle/release/app-release.aab
          release-version: ${{ github.ref_name }}
          release-name: Production candidate
          release-owner: release@company.com
          fail-on-no-go: true
Portable CLI sequence 
gantry release ensure "$RELEASE_VERSION" \
  --name "Production candidate" \
  --owner "release@company.com"
gantry release candidate ensure "$RELEASE_VERSION" \
  --artifact "$SIGNED_ARTIFACT"
gantry release audit "$RELEASE_VERSION" --reuse-unchanged --ci
gantry release packet "$RELEASE_VERSION"

Make the gate authoritative

1 Build once Pass the exact signed store candidate to mobile-artifact; do not rebuild after the audit.
2 Require the check Protect the release branch and require the mobile-release-gate job before merge or promotion.
3 Retain the record Commit policy changes and retain .gantry/releases/; download the uploaded verified packet for review.
